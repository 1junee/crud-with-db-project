# DESIGN.md

이 프로젝트 화면의 디자인 규칙입니다. 기준 이미지는 같은 폴더의 `ref1.png`(카드형 글 목록 화면)이고, 수치는 이미지에서 잰 값입니다.
새 페이지를 만들거나 기존 페이지를 고칠 때는 이 문서를 먼저 확인하고, 문서에 없는 결정을 내렸다면 이 문서에 추가합니다.
기준 이미지의 레이아웃과 규격만 참고하며, 원본 서비스의 이름·로고·이미지는 사용하지 않습니다.

## 1. 전체 원칙

- 화면은 밝고 조용해야 합니다. 배경은 아주 연한 회색, 콘텐츠는 흰 카드 위에 올리고, 색은 글자와 버튼에만 최소한으로 씁니다.
- 장식보다 콘텐츠(제목과 본문)가 먼저 보여야 합니다. 테두리 대신 여백과 옅은 그림자로 영역을 나눕니다.
- 강조색은 따로 두지 않습니다. 가장 중요한 버튼과 선택된 탭만 거의 검정색으로 칠해 눈에 띄게 합니다.
- DB에 없는 정보(작성 시간, 작성자, 좋아요 등)는 가짜 값으로 채우지 않습니다. 그 자리는 실제로 있는 값으로 대신하거나 비워 둡니다.

## 2. 색

| 이름 | 값 | 쓰는 곳 |
|---|---|---|
| `--bg` | `#f8f9fa` | 페이지 배경 |
| `--card` | `#ffffff` | 카드 배경 |
| `--text` | `#212529` | 제목, 강조 글자, 기본 버튼, 선택된 탭 |
| `--sub` | `#495057` | 본문 미리보기 글자 |
| `--muted` | `#868e96` | 시간·개수 같은 작은 보조 글자, 선택되지 않은 탭 |
| `--line` | `#f1f3f5` | 카드 안 구분선, 아바타 동그라미 배경 |
| `--border` | `#dee2e6` | 입력칸·보조 버튼 테두리 |

- 색은 반드시 위 CSS 변수로만 씁니다. 페이지 안에 색 코드를 직접 쓰지 않습니다.
- 글자색은 중요도에 따라 `--text` → `--sub` → `--muted` 세 단계만 씁니다.
- 아이콘은 옆 글자와 같은 색을 씁니다.

## 3. 글꼴

- 본문 글꼴은 시스템 고딕을 씁니다: `-apple-system, BlinkMacSystemFont, "Apple SD Gothic Neo", "Noto Sans KR", sans-serif`.
- 로고만 고정폭 글꼴(`Menlo`, `Consolas`, `monospace`)을 써서 개발 블로그 느낌을 냅니다. 로고는 22px 안팎, 굵기는 보통입니다.
- 글자 크기는 아래 단계만 씁니다.

| 용도 | 크기 | 굵기 | 줄 간격 |
|---|---|---|---|
| 페이지 제목 (상세·작성·수정) | 28px | 700 | 1.4 |
| 탭 | 18px | 700 (선택) / 400 (기본) | 1 |
| 상세 본문 | 16px | 400 | 1.8 |
| 입력칸 | 16px | 400 | 1.6 |
| 빈 화면 안내 문구 | 16px | 400 | 1.5 |
| 카드 제목 | 16px | 700 | 1.5 |
| 버튼 | 15px | 700 | 1 |
| 카드 본문 미리보기, 입력칸 라벨 | 14px | 400 (라벨은 700) | 1.5 |
| 보조 정보, 맨 아래 줄 | 12px | 400 (이름 등 강조는 700) | 1.5 |

## 4. 레이아웃

- 콘텐츠 최대 폭은 1024px이며 가운데 정렬합니다. 화면이 좁을 때는 양옆에 16px 여백을 둡니다.
- 페이지 맨 위에 2px 짙은 선을 둘 수 있습니다(선택 사항).
- 위에서부터 순서는 **상단 바 → 탭 줄 → 카드 그리드**입니다.

### 4-1. 상단 바

- 높이는 64px이고, 왼쪽에 로고, 오른쪽에 아이콘들과 주요 버튼을 둡니다. 세로 가운데 정렬합니다.
- 오른쪽 아이콘은 선택 사항입니다. 넣는다면 24px 크기, 서로 20px 정도 띄우고, 실제로 동작하는 것만 둡니다. 지금은 해당 기능이 없어 아이콘을 두지 않습니다.
- 주요 버튼(로그인, 새 글 작성 등)은 하나만 둡니다. 배경 `--text`, 글자 흰색, 알약 모양(`border-radius: 999px`), 높이 32px, 좌우 여백 16px, 글자 15px입니다.
- 마우스를 올리면 버튼 배경이 `--sub`로 약간 밝아집니다.

### 4-2. 탭 줄

- 상단 바 아래 24px 띄우고, 탭 줄과 카드 사이는 32~48px 띄웁니다.
- 탭 하나는 폭 약 112px, 높이 48px이며, 왼쪽에 24px 아이콘 + 8px 간격 + 글자 순서입니다.
- 선택된 탭은 글자 `--text`, 굵기 700, 아래에 2px `--text` 밑줄을 둡니다. 선택되지 않은 탭은 `--muted`, 밑줄 없음입니다.
- 탭 이름 뒤에 한 칸 띄우고 해당 글 개수를 둘 수 있습니다(예: `전체 12`). 개수는 선택 여부와 상관없이 `--muted`, 굵기 400입니다.
- 실제로 작동하는 페이지가 있는 탭만 만듭니다. 링크 없는 탭을 장식으로 두지 않습니다.
- 탭 줄 오른쪽 끝에는 더보기(⋮) 메뉴 하나만 둘 수 있습니다.

### 4-3. 카드 그리드

- CSS grid로 한 줄에 3개, 칸 사이 간격은 가로·세로 모두 32px입니다.
- 열 정의는 `repeat(3, minmax(0, 1fr))`처럼 `minmax(0, …)`를 씁니다. 그래야 긴 제목이 칸 폭을 늘리지 않습니다.
- 화면 폭 1024px 이하에서는 2개, 640px 이하에서는 1개로 줄이고, 1개일 때 간격은 16px로 줄입니다.
- 같은 줄의 카드는 높이가 같습니다(약 380px). 내용이 짧아도 카드 높이를 줄이지 않고, 맨 아래 줄이 항상 바닥에 붙어 있게 합니다.

## 5. 카드

카드는 위에서부터 **(썸네일) → 본문 영역 → 맨 아래 줄** 세 부분입니다.

### 5-1. 겉모양

- 배경 `--card`, 모서리 4px, 테두리 없음, 그림자 `0 4px 16px rgba(0,0,0,.04)`입니다.
- 마우스를 올리면 위로 8px 떠오르고 그림자가 `0 12px 20px rgba(0,0,0,.08)`로 진해집니다. 전환은 0.25초입니다.
- 카드 전체가 하나의 링크입니다. 어디를 눌러도 상세 페이지로 이동합니다.

### 5-2. 썸네일 (이미지가 있을 때만)

- 카드 맨 위에 꽉 차게 넣고, 비율은 약 1.92 : 1(폭 320px 기준 높이 167px)입니다. `object-fit: cover`로 잘라서 채웁니다.
- 이미지가 없으면 썸네일 자리를 비워 두지 않고 바로 본문 영역부터 시작합니다. 대신 본문 미리보기를 더 길게 보여 줍니다.

### 5-3. 본문 영역

- 안쪽 여백은 16px입니다.
- 제목은 한 줄만 보이고, 넘치면 `…`로 자릅니다. 제목 아래 4px 띄우고 본문 미리보기를 둡니다.
- 본문 미리보기는 썸네일이 있으면 최대 3줄, 없으면 최대 5~6줄까지 보이고 넘치면 `…`로 자릅니다(`-webkit-line-clamp`).
- 보조 정보 줄(예: `방금 전 · 0개의 댓글`)은 본문 영역 맨 아래에 붙입니다(`margin-top: auto`). 본문 미리보기와는 최소 16px 띄웁니다. 12px, `--muted`이고, 항목 사이는 ` · `로 구분합니다.
- 이 프로젝트에는 시간·댓글 데이터가 없으므로, 보조 정보 줄에는 `본문 N자`처럼 실제 값을 넣습니다.

### 5-4. 맨 아래 줄

- 위에 1px `--line` 구분선, 안쪽 여백 위아래 10px·좌우 16px, 글자 12px입니다.
- 기준 이미지에서는 왼쪽에 24px 동그라미 아바타 + 8px 간격 + `by` + 굵은 이름, 오른쪽에 아이콘 + 숫자가 있습니다.
- 이 프로젝트에는 작성자·좋아요 데이터가 없으므로 다음처럼 바꿔서 씁니다(이 규칙이 기준입니다).
  - 왼쪽: 24px 동그라미 아바타(`--line` 배경, 제목 첫 글자, 12px 굵게, `--sub`) + 8px 간격 + `No. ` + 굵은 글 번호(두 자리, 예: `No. **01**`, 번호만 `--text`).
  - 오른쪽: `읽기 →` (`--muted`). 카드에 마우스를 올리면 `--text`로 바뀝니다.

## 6. 상태

- 글이 하나도 없으면 그리드 한 줄 전체를 차지하는 빈 화면을 보여 줍니다(`grid-column: 1 / -1`). 위아래 여백 96px, 가운데 정렬로 안내 문구(`--muted`, 16px)와 그 아래 20px 띄워 주요 버튼 하나를 둡니다.
- 마우스를 올리는 효과는 위로 뜨기, 그림자, 글자색 변화만 씁니다. 크기가 커지거나 회전하는 효과는 쓰지 않습니다.

## 7. 코드 작성 규칙

- **Bootstrap 버전은 항상 5.3으로 고정합니다.** 현재 CDN 주소는 `https://cdn.jsdelivr.net/npm/bootstrap@5.3.3/dist/css/bootstrap.min.css`이고 `integrity`(SRI)·`crossorigin` 속성을 함께 씁니다.
  - `bootstrap@5`, `bootstrap@latest`처럼 범위로 쓰지 않고 정확한 버전을 적습니다.
  - 5.4, 6.x 등 다른 버전으로 올리지 않습니다. 5.3 안의 패치 버전(5.3.x)으로 바꿀 때만 SRI 해시를 함께 바꿉니다.
  - 문서·예제를 찾아볼 때도 5.3 버전 문서를 기준으로 합니다(v6 alpha 문법 사용 금지).
- 이 문서의 규격은 `static/css/board.css`에서 Bootstrap 기본값을 덮어써서 맞춥니다. `board.css`는 반드시 Bootstrap **다음에** 불러옵니다.
- 지금은 Bootstrap JS 기능(드롭다운, 모달 등)을 쓰지 않아 CSS만 불러옵니다. JS가 필요해지면 같은 5.3.x 버전의 `bootstrap.bundle.min.js`를 `base.html`의 `</body>` 바로 앞에 추가합니다.
- HTML 안에는 CSS를 쓰지 않습니다(`<style>` 태그, `style=""` 속성 모두 금지). 스타일은 `board.css` 한 곳에만 둡니다.
- 정렬·여백·글자 자르기처럼 Bootstrap 유틸리티 클래스(`d-flex`, `justify-content-between`, `mt-4`, `text-truncate` 등)로 되는 것은 유틸리티를 씁니다. 색은 Bootstrap 색 유틸리티(`text-primary`, `bg-light` 등) 대신 우리 CSS 변수를 씁니다.
- Bootstrap 컴포넌트는 `.card`, `.btn`, `.form-control`, `.form-label`을 씁니다. Bootstrap의 `--bs-*` 변수를 우리 색 변수로 연결해서 덮어씁니다(예: `.btn-primary`의 `--bs-btn-bg`를 `var(--text)`로).
- 카드 그리드는 반응형 기준점(1024px·640px)이 Bootstrap 그리드와 달라서 Bootstrap `row`/`col` 대신 직접 만든 `.post-grid`를 씁니다.
- 색·크기는 `:root`의 CSS 변수로 관리합니다.
- 반응형 기준점은 1024px, 640px 두 개만 씁니다.
- 아이콘은 인라인 SVG로 넣고 `stroke="currentColor"`로 글자색을 따라가게 합니다.
- 장식용 아이콘·글자에는 `aria-hidden="true"`를 붙입니다.

## 8. 상세·작성·수정 페이지

기준 이미지에는 목록 화면만 있으므로, 아래는 목록 규칙을 이어서 정한 규칙입니다.

### 8-1. 공통 틀

- 모든 페이지는 `templates/base.html`을 이어받습니다(`{% extends 'base.html' %}`). Bootstrap과 `board.css`는 `base.html`에서만 불러옵니다.
- 상세·작성·수정 화면은 그리드 대신 가운데 놓인 단독 카드(`.card.panel`) 하나를 씁니다. 최대 폭 768px, 상단 바 아래 24px, 모서리와 그림자는 목록 카드와 같습니다. 단독 카드는 마우스를 올려도 떠오르지 않습니다.
- 단독 카드는 본문 영역(안쪽 여백 32px, 640px 이하에서는 위아래 24px·좌우 16px)과 맨 아래 줄(위 1px `--line` 구분선, 안쪽 여백 위아래 16px·좌우 32px, 640px 이하에서는 12px·16px)로 나눕니다.
- 페이지 제목은 28px, 굵기 700입니다. 제목 아래 8px 띄워 12px `--muted` 보조 정보(`No. 01 · 본문 N자`)를 둡니다.

### 8-2. 버튼

- 버튼은 세 종류만 씁니다. 모두 높이 32px, 알약 모양, 15px, 굵기 700입니다.
  - 주요 버튼(`.btn-primary`): 배경 `--text`, 흰 글자. 한 화면에 하나만 둡니다(새 글 작성, 등록, 저장).
  - 보조 버튼(`.btn-ghost`): 흰 배경, `--border` 테두리, `--sub` 글자. 마우스를 올리면 테두리와 글자가 `--text`가 됩니다(수정, 삭제).
  - 글자 버튼(`.btn-text`): 배경·테두리 없이 `--muted` 글자, 좌우 여백 8px. 마우스를 올리면 `--text`가 됩니다. 되돌아가는 동작에 씁니다(목록, 취소).
- 맨 아래 줄에서 되돌아가는 버튼은 왼쪽, 실행 버튼은 오른쪽에 둡니다. 오른쪽에 버튼이 여러 개면 사이를 8px(`gap-2`) 띄웁니다.
- 버튼에 포커스 그림자는 쓰지 않습니다(`--bs-btn-focus-box-shadow: none`).
- 작성·수정 화면에서는 상단 바의 `새 글 작성` 버튼을 숨깁니다.
- 삭제는 빨간색 등 강조색을 쓰지 않고 보조 버튼으로 두며, 대신 실행 전에 확인창을 띄웁니다.

### 8-3. 상세 본문

- 본문은 제목 영역 아래 1px `--line` 구분선과 위아래 32px 여백을 두고 시작합니다.
- 16px, 줄 간격 1.8, `--sub` 색이며, 작성자가 넣은 줄바꿈을 그대로 보여 줍니다(`white-space: pre-wrap`).

### 8-4. 입력칸

- 라벨은 입력칸 위에 14px 굵게, 아래 8px 간격입니다. 입력 묶음 사이는 24px입니다.
- 입력칸은 폭 100%, 안쪽 여백 12px·16px, `--border` 1px 테두리, 모서리 4px, 글자 16px입니다. 입력 중에는 테두리를 `--text`로 바꿉니다.
- 내용은 여러 줄 입력칸(`textarea`)을 쓰고 최소 높이 320px, 세로로만 크기를 조절할 수 있게 합니다.
- 입력칸은 Bootstrap `.form-label`, `.form-control`을 쓰고, 위 규격은 `board.css`에서 덮어씁니다. 입력 묶음 사이 간격은 `mt-4`(24px)입니다.
